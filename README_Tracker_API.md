## Импорт в Insomnia

1. Открой Insomnia
2. **File → Import → From File**
3. Выбери `Tracker_API_Insomnia.yaml`

## Переменные окружения

После импорта создай окружение (**Environments → Manage Environments**) и добавь переменные:

```json
{
  "token": "<твой OAuth-токен>",
  "org_id": "<ID организации>"
}
```

| Переменная | Заголовок | Где используется |
|---|---|---|
| `token` | `Authorization: OAuth {{token}}` | Все запросы |
| `org_id` | `X-Org-ID: {{org_id}}` | Организация Яндекс 360 для бизнеса |

> Если организация привязана к **Yandex Cloud**, замени заголовок `X-Org-ID` на `X-Cloud-Org-ID` вручную в нужных запросах.

## Получение OAuth-токена

1. Перейди на [https://oauth.yandex.ru](https://oauth.yandex.ru) и создай приложение, или используй существующий токен
2. Запроси доступ: **tracker:read** (чтение) и/или **tracker:write** (запись)
3. Подробнее: [Доступ к API](https://yandex.ru/support/tracker/ru/api-ref/access)

## Базовый URL

```
https://api.tracker.yandex.net/v3/
```

## Параметры в URL

Запросы содержат плейсхолдеры — замени их на реальные значения перед отправкой:

| Плейсхолдер | Пример значения |
|---|---|
| `{issueId}` | `TREK-123` |
| `{queueId}` | `TREK` |
| `{boardId}` | `42` |
| `{entityType}` | `project`, `portfolio`, `goal` |
| `{entityId}` | `63a5dc2b1*****` |
| `{commentId}` | `18` |
| `{sprintId}` | `7` |

## Структура запроса

Каждый запрос уже содержит:
- Заголовок `Authorization` с `{{token}}`
- Заголовок `X-Org-ID` с `{{org_id}}`
- Заголовок `Content-Type: application/json` (для POST/PATCH)
- Пример тела запроса в формате JSON (для POST/PATCH)
- Query-параметры с пагинацией (`perPage`, `page`) где применимо
